# Simple Expense Calculator

An Android application built with Kotlin and XML layouts that allows users to enter expense amounts and categories to track and calculate total expenses[cite: 1].

## Features
* **Expense Input:** Easily add expense amounts and corresponding categories[cite: 1].
* **Real-Time Total:** Automatically calculates and updates the sum of all entered expenses.
* **Expense List:** Maintains and displays a scrollable history of recorded expenses[cite: 1].

## Tools & Technologies
* **IDE:** Android Studio[cite: 1]
* **Language:** Kotlin[cite: 1]
* **UI:** XML Layouts & Material Design Components

## How to Run
1. Open the project folder in **Android Studio**[cite: 1].
2. Wait for Gradle to finish syncing dependencies.
3. Connect your Android device or start a virtual emulator.
4. Click the **Run (Green Play) button** to build and launch the app.
